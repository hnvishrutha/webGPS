# TasteSkill / Impeccable UI Design

## Principles
1. **Visual Hierarchy & Typography**: Clean font pairings, legible sizing, deliberate line-heights, and distinct hierarchy for headings, labels, and badges.
2. **Refined Color Palette**: Intentional color systems with high contrast ratios, subtle borders, gentle shadows, and meaningful status colors (verified = green, caution = amber, danger = red).
3. **Micro-Interactions & States**: Smooth transitions, clear hover/active/focus states, intuitive loading skeletons, and interactive feedback.
4. **Layout & Spacing**: Generous whitespace, consistent padding, alignment, and modern border radiuses.
5. **Ergonomic Side Panels**: Compact yet breathing UI tailored for Chrome Extension side panels, maintaining readability at 360-400px width.
