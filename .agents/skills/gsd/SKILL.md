# GSD: Get Shit Done

## Principles
1. **Bias for Action**: Move swiftly from planning to working implementation.
2. **Relentless Focus on Deliverables**: Keep the end goal and deadline in mind. Deliver working software incrementally.
3. **Pragmatic Problem Solving**: Identify blockers early and deploy solid fallbacks (such as robust mock modes) so execution never stalls.
4. **Step-by-Step Momentum**: Complete each defined step thoroughly, verify it passes criteria, and keep momentum high.
5. **No Overhead**: Zero unnecessary abstractions or gold-plating outside the target MVP scope.
