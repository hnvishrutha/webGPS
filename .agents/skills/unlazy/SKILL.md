# Unlazy: Complete & Thorough Implementation

## Principles
1. **No Placeholders**: Never leave `TODO`, `FIXME`, `...`, or `/* implement later */` in code. Write complete, working code every single time.
2. **Defensive Programming**: Validate inputs, handle network errors, check existence of DOM nodes, handle nulls and timeouts gracefully.
3. **Thorough Edge Cases**: Account for empty states, missing attributes, malformed JSON, and offline scenarios.
4. **Self-Contained & Tested**: Ensure every component works out of the box with zero missing dependencies or omitted lines.
